# Инструменты управления версиями

Этот каталог содержит утилиты для управления версиями проекта Clerkonator.

## Доступные утилиты

### 1. `save_version.py` - Сохранение версии в историю
Создает снимок текущего состояния проекта в папке `versions/`.

**Использование:**
```bash
python tools/save_version.py
```

**Что делает:**
- Читает текущую версию из `version.json`
- Создает папку `versions/v{версия}_{дата_время}`
- Копирует все файлы проекта (исключая большие папки)
- Исключает: `venv`, `models`, `data`, `logs`, `versions`, кэш-файлы

### 2. `create_release.py` - Создание релизного архива
Создает ZIP-архив для распространения пользователям.

**Использование:**
```bash
python tools/create_release.py
```

**Что делает:**
- Создает архив `Clerkonator_v{версия}_{дата_время}.zip`
- Включает только необходимые файлы для пользователей
- Исключает: модели, данные, логи, тесты, виртуальные окружения
- Показывает размер созданного архива

### 3. `bump_version.py` - Обновление версии
Увеличивает patch-версию проекта.

**Использование:**
```bash
python tools/bump_version.py
```

**Что делает:**
- Читает текущую версию из `version.json`
- Увеличивает patch-номер (например: 1.0.2 → 1.0.3)
- Обновляет `last_updated` в `version.json`

## Типичный workflow

1. **Сохранить текущую версию в историю:**
   ```bash
   python tools/save_version.py
   ```

2. **Создать релизный архив:**
   ```bash
   python tools/create_release.py
   ```

3. **Обновить версию для дальнейшей работы:**
   ```bash
   python tools/bump_version.py
   ```

## Особенности

- Все утилиты работают с кодировкой UTF-8
- Логирование с временными метками
- Автоматическое исключение ненужных файлов
- Безопасная обработка ошибок
- Поддержка Windows и Linux

## Структура папки versions/

```
versions/
├── v1.0.0_20251020_120000/    # Снимок версии 1.0.0
├── v1.0.1_20251020_130000/    # Снимок версии 1.0.1
└── v1.0.2_20251020_140000/    # Снимок версии 1.0.2
```

Каждый снимок содержит полную копию проекта на момент создания.
