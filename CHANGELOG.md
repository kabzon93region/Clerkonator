# Changelog

Все значимые изменения проекта Clerkonator.

## [1.0.5] - 2026-06-29

### Добавлено
- **STT-сервер с tray-иконкой** — отдельный серверный процесс `Clerkonator-Server.exe` с иконкой в системном трее
- **Поддержка Whisper GPU** — интеграция faster-whisper для распознавания на GPU (CUDA)
- **Автоматическая загрузка моделей** — модели Vosk и Whisper скачиваются автоматически при первом запуске
- **Каталог моделей** — поддержка нескольких моделей с переключением через меню трея
- **Разделение конфигурации** — `config.client.json` и `config.server.json` для клиента и сервера
- **REST API** — HTTP-интерфейс для управления сервером (`/api/health`, `/api/transcribe`, `/api/switch-model`, `/api/reload`, `/api/shutdown`)
- **Скрипт публикации** — `publish.cmd` для автоматической публикации на GitHub через gh CLI
- **Скрипт setup.cmd в корне** — удобная настройка одним кликом

### Изменено
- **Ребрендинг** — проект переименован в "Clerkonator"
- **Обновлён .gitignore** — дедубликация правил, добавлены паттерны для AI IDE (Copilot, Cursor, Qoder, Windsurf, Cline, Aider)
- **Улучшена документация** — обновлены руководства пользователя и разработчика

### Исправлено
- **Безопасное переключение моделей** — переключение заблокировано во время загрузки модели, предотвращает зависание сервера
- **Генерационный счётчик** — защита от race conditions при одновременной загрузке нескольких моделей
- **Освобождение памяти** — улучшен `cleanup()` для гарантированного освобождения VRAM/RAM при смене модели
- **Отмена загрузки** — добавлен callback `is_cancelled` для ранней отмены длительных операций (GPU warmup, Model())
- **Меню моделей в трее** — пункты меню блокируются (серые) во время загрузки, обновляются после завершения
- **HTTP 409 Conflict** — API возвращает правильный статус при попытке переключить модель во время загрузки
