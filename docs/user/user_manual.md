# Руководство пользователя Clerkonator

## 🎯 Введение

Clerkonator — это приложение для преобразования речи в текст с удобным графическим интерфейсом. Программа позволяет записывать аудио с микрофона, преобразовывать его в текст и автоматически копировать результат в буфер обмена.

## 📋 Системные требования

### Минимальные требования
- **Операционная система**: Windows 10/11
- **Python**: 3.8 или выше
- **ОЗУ**: 2 ГБ (4+ ГБ для локального Whisper)
- **Свободное место**: 500 МБ (+ модели STT)
- **Микрофон**: Любой совместимый с Windows
- **GPU (сервер)**: NVIDIA с CUDA (рекомендуется 4+ ГБ VRAM)

## 🚀 Установка

### Автоматическая установка

#### Windows
1. Скачайте проект
2. Запустите `setup.cmd` (двойной клик)
3. Следуйте инструкциям на экране
4. После установки запустите `run.cmd`

#### Linux/macOS
1. Скачайте проект
2. Откройте терминал в папке проекта
3. Выполните: `./install.sh`
4. После установки запустите: `./run.sh`

### Ручная установка

1. **Установите Python 3.7+**
   - Windows: [python.org](https://python.org)
   - Linux: `sudo apt install python3 python3-pip`
   - macOS: `brew install python3`

2. **Создайте виртуальное окружение**
   ```bash
   python -m venv venv
   ```

3. **Активируйте окружение**
   ```bash
   # Windows
   venv\Scripts\activate
   
   # Linux/macOS
   source venv/bin/activate
   ```

4. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

5. **Модели STT** — см. [Модели STT](./models.md): Vosk в `models/`, Whisper через `download_whisper_model.cmd`

## 🎮 Использование

### Первый запуск

1. **Запустите приложение**
   - Windows: `run.cmd` или `python main.py`

2. **Подключите распознавание**
   - **Сервер (LAN):** на машине с GPU — `run_server.cmd`; в настройках клиента укажите IP и «Подключиться»
   - **Локально:** «Локально (офлайн)» → выберите модель → «Загрузить локальную модель»
   - STT при старте клиента **не** загружается автоматически

3. **Откройте окно**
   - Трей → «Открыть интерфейс» или горячая клавиша из `config.client.json`

4. **Проверьте микрофон** в настройках (список устройств)

### Основные функции

#### Запись аудио
1. Нажмите **🎙️ Начать запись**
2. Говорите в микрофон
3. Следите за таймером записи
4. Нажмите **⏸️ Пауза** для приостановки
5. Нажмите **⏹️ Завершить** для остановки

#### Преобразование в текст
1. После завершения записи начнется автоматическое преобразование
2. Следите за прогрессом в окне программы
3. Результат появится в текстовом поле
4. Текст автоматически скопируется в буфер обмена

#### Загрузка и конвертация файла
1. Нажмите **Load Audio File** и выберите файл
2. **Play Audio** — прослушать (поддерживаются WAV, MP3, FLAC и др. через pygame)
3. **Convert to Text** — распознать речь в текст

> **Важно про форматы:** для **распознавания** нужен файл **WAV: моно, 16-bit, 16000 Hz**. Записи с микрофона сохраняются в этом формате автоматически. Внешние MP3/FLAC можно **прослушать**, но **Convert to Text** сработает только если файл соответствует требованиям Vosk (или предварительно конвертирован, например в Audacity).

#### Работа с результатом
1. Текст отображается в окне программы
2. Нажмите **📋 Копировать в буфер** для повторного копирования
3. Вставьте текст в любое приложение (`Ctrl+V`)

### Горячие клавиши

Настраиваются в окне **Настройки** (захват сочетания) или в `config.client.json`:

| Параметр | По умолчанию | Действие |
|----------|--------------|----------|
| `hotkeys.show_window` | `Ctrl+Alt+E` | Показать/скрыть окно |
| `hotkeys.record_toggle` | `Ctrl+Alt+R` | Старт/стоп записи + распознавание |
| `hotkeys.pause_recording` | `Ctrl+Alt+P` | Пауза/продолжить запись |
| `hotkeys.cancel_recording` | `Ctrl+Alt+X` | Отменить запись |

Все горячие клавиши работают **глобально** (через pynput), даже когда окно свёрнуто в трей.

## ⚙️ Настройки

### Конфигурационные файлы

| Файл | Описание |
|------|----------|
| `config.client.json` | Клиент: клавиши, микрофон, GUI, подключение к серверу, локальные модели |
| `config.server.json` | Сервер: порт, GPU/CPU, модель Whisper |

Пример фрагмента **клиента**:

```json
{
  "stt": {
    "mode": "none",
    "language": "ru",
    "remote": {
      "host": "192.168.0.10",
      "port": 8765
    },
    "local": {
      "device": "gpu",
      "model": "large-v3-turbo"
    },
    "recognition": {
      "source_language": "ru",
      "translate": false,
      "target_language": "en"
    },
    "options": {
      "whisper_cache_dir": "models/whisper",
      "whisper_use_system_proxy": false,
      "fallback_cpu": true
    }
  }
}
```

Пример **сервера** (модель Whisper):

```json
{
  "listen": { "port": 8765 },
  "server": {
    "max_queue_size": 20
  },
  "stt": {
    "language": "ru",
    "server": {
      "device": "gpu",
      "whisper_model": "large-v3-turbo",
      "whisper_cache_dir": "models/whisper"
    }
  }
}
```

| Параметр | По умолчанию | Смысл |
|----------|--------------|--------|
| `server.max_queue_size` | `20` | Максимальное количество задач в очереди. Если очередь заполнена — новые запросы отклоняются с ошибкой 503 |

### Язык и перевод

В настройках (секция **«Язык и перевод»**) и в `config.client.json`:

```json
"recognition": {
  "source_language": "ru",
  "translate": false,
  "target_language": "en"
}
```

| Параметр | По умолчанию | Смысл |
|----------|--------------|--------|
| `source_language` | `ru` | Язык речи (`ru`, `en`, `auto`, …) |
| `translate` | `false` | Не переводить — выдать текст на языке речи |
| `target_language` | `en` | Куда переводить, если `translate: true` (Whisper — только на английский) |

Параметры передаются на **сервер в каждом запросе** (HTTP-заголовки `X-STT-*`). Локальный Whisper использует те же настройки.

### Модели и скачивание Whisper

**Обязательно к прочтению:** [models.md](./models.md) — таблицы Vosk/Whisper, VRAM, качество.

Кратко:

1. Укажите `stt.local.model` в `config.client.json` (локально) или `stt.server.whisper_model` на сервере.
2. Запустите:

```cmd
download_whisper_model.cmd
```

Для клиентского конфига:

```cmd
download_whisper_model.cmd --profile client
```

3. Другая модель без правки конфига: `download_whisper_model.cmd --model large-v3`
4. Список имён: `download_whisper_model.cmd --list`

По умолчанию в проекте: **`large-v3-turbo`**.

### Изменение настроек

1. **Горячие клавиши** — окно «Настройки» или `config.client.json`
2. **Микрофон и буфер** — «Настройки» → секция «Аудио»
3. **Режим STT** — «Сервер (LAN)» или «Локально» в настройках
4. **Модель сервера** — `config.server.json`, затем `download_whisper_model.cmd`

## 🎤 Советы по использованию

### Для лучшего распознавания

1. **Качество микрофона**
   - Используйте качественный микрофон
   - Избегайте фонового шума
   - Говорите четко и не слишком быстро

2. **Окружение**
   - Работайте в тихом помещении
   - Избегайте эха и реверберации
   - Держите микрофон на постоянном расстоянии

3. **Речь**
   - Говорите естественно
   - Делайте паузы между предложениями
   - Избегайте слишком длинных записей

### Оптимизация производительности

1. **Закройте ненужные программы**
2. **Освободите место на диске**
3. **Используйте SSD для лучшей производительности**
4. **Не записывайте слишком длинные аудио (рекомендуется до 10 минут)**

### GPU и распознавание

- **STT-сервер** (`run_server.cmd`) использует **Whisper на GPU** (NVIDIA), модель по умолчанию `large-v3-turbo`.
- **Локально** доступны Vosk (CPU) и Whisper (GPU при наличии CUDA, иначе CPU).
- Скачивание Whisper: `download_whisper_model.cmd` — см. [models.md](./models.md).

## 🔧 Устранение неполадок

### Частые проблемы

#### Приложение не запускается
**Проблема**: Ошибка при запуске
**Решение**:
1. Проверьте установку Python
2. Убедитесь, что виртуальное окружение активировано
3. Переустановите зависимости: `pip install -r requirements.txt`

#### Микрофон не работает
**Проблема**: Не слышно звук при записи
**Решение**:
1. Проверьте подключение микрофона
2. Проверьте настройки микрофона в системе
3. Убедитесь, что микрофон не используется другими программами
4. Проверьте права доступа к микрофону

#### Плохое распознавание речи
**Проблема**: Неправильный или неполный текст
**Решение**:
1. Перейдите на более точную модель — см. [models.md](./models.md) (`large-v3-turbo` или `large-v3` на сервере с GPU)
2. Используйте режим **сервер (LAN)** вместо локального Whisper на CPU
3. Проверьте микрофон и фоновый шум
4. Говорите чётко, не слишком быстро

#### Конвертация файла не даёт текста
**Проблема**: После «Convert to Text» результат пустой или ошибка
**Решение**:
1. Убедитесь, что файл в формате WAV: моно, 16-bit, 16000 Hz
2. MP3/FLAC сначала конвертируйте (Audacity, ffmpeg и т.п.)
3. Записи с микрофона уже в нужном формате — используйте их как эталон

#### Модель Whisper не скачивается
**Решение**:
1. Укажите модель в `config.server.json` → `stt.server.whisper_model`
2. Запустите `download_whisper_model.cmd`
3. При ошибке прокси: `"whisper_use_system_proxy": false` в конфиге
4. Подробнее: [models.md](./models.md)

#### Модель Vosk не найдена
**Проблема**: Ошибка "Модель Vosk не найдена"
**Решение**:
1. Проверьте подключение к интернету
2. Перезапустите приложение - модель скачается автоматически
3. Если скачивание не удается, скачайте модель вручную с https://alphacephei.com/vosk/models
4. Распакуйте архив в папку `models/`

#### Горячие клавиши не работают
**Проблема**: Комбинации клавиш не срабатывают
**Решение**:
1. Проверьте, что приложение запущено
2. Убедитесь, что окно приложения активно
3. Проверьте конфликты с другими программами
4. Измените комбинацию клавиш в настройках
