# 🚀 Инструкция по запуску Clerkonator

## Быстрый старт

### Автоматическая установка и запуск

#### Windows
```cmd
setup.cmd    # Установка
run.cmd      # Запуск
```

### Ручной запуск

#### 1. Активация виртуального окружения
```cmd
venv\Scripts\activate
```

#### 2. Запуск приложения
```cmd
python main.py
```

### 3. Использование
- **Правый клик по иконке в трее** - открыть контекстное меню
- **"Открыть интерфейс"** - показать главное окно
- **🎙️ Начать запись** - для записи с микрофона
- **⏸️ Пауза** - для приостановки записи
- **⏹️ Завершить** - для остановки и обработки
- Результат автоматически скопируется в буфер обмена

## Контекстное меню

- **🎤 Открыть интерфейс** - показать главное окно
- **📊 System Information** — сведения о системе (CPU, ОЗУ)
- **⚙️ Настройки** - доступ к настройкам
- **❓ О программе** - информация о версии
- **🚪 Выход** - закрыть приложение

## Тестирование

Для проверки работоспособности запустите:
```cmd
python tests\test_app.py
```

## STT-сервер (GPU в LAN)

```cmd
pip install -r requirements-server.txt
download_whisper_model.cmd
run_server.cmd
```

Модель по умолчанию: **large-v3-turbo** (~1.6 ГБ VRAM).
Параметр `server.max_queue_size` в `config.server.json` — лимит очереди задач (по умолчанию 20).

## Структура файлов

```
Clerkonator/
├── main.py              # Клиент
├── stt/server_app.py    # STT-сервер
├── gui/                 # Графический интерфейс
├── audio/               # Запись/воспроизведение
├── utils/               # Утилиты
├── config.client.json   # Настройки клиента
├── config.server.json   # Настройки сервера
├── models/              # Модели Vosk и Whisper
├── data/recordings/     # Аудио файлы
└── data/transcriptions/ # Текстовые файлы
```

## Требования

- Python 3.8+
- Windows 10/11
- Микрофон
- STT: сервер (Whisper GPU по LAN) или локально (Vosk CPU / Whisper)
- Для сервера: NVIDIA GPU с CUDA (рекомендуется)

## Возможные проблемы

1. **Ошибка "No module named 'pyaudio'"**
   - Убедитесь, что виртуальное окружение активировано
   - Запустите: `.\venv\Scripts\python.exe main.py`

2. **Модель не найдена**
   - Проверьте наличие папки `models/vosk-model-ru-0.42`
   - Убедитесь, что модель не повреждена
   - При первом запуске нужен интернет для автоматической загрузки

3. **Проблемы с микрофоном**
   - Проверьте настройки микрофона в Windows
   - Убедитесь, что микрофон не используется другими приложениями

## Поддержка

При возникновении проблем проверьте:
1. Все зависимости установлены
2. Модель Vosk на месте
3. Микрофон работает
4. Виртуальное окружение активировано
